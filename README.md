# 直觉之后 · 第三版

以《思考，快与慢》为线索的认知互动手册。先作出判断，再统一回看。7个可多选模块，每模块5个情境，共35题。

默认勾选原来的四章，以15—20分钟为设计目标。新增三章可以单独选；全部七章约35分钟。每章约5分钟，均为阅读与交互的设计预估，仍需真实用户计时。

## 本地运行

无构建步骤。在本目录运行 `python3 -m http.server 4173 --bind 127.0.0.1`，访问 http://127.0.0.1:4173/ 。另提供包含图片、CSS和脚本的单文件HTML。

无需登录，无服务器端答案存储，不请求分析服务或外部字体。进度仅保存在当前浏览器、当前地址。第三版存储键为after-intuition-v3；没有第三版存档时可读取同地址第二版进度并保留既有作答。单文件与HTTP地址之间不共享进度。部分浏览器会限制file协议存储或下载，此时使用HTTP预览。

## 交互与设计

首页采用章节目录与勾选记录，题面采用开放阅读版面。沿用全部原有题目、来源与作答机制。揭秘每模块2页，分段展开，同一页只打开一个解释。报告只解读参与模块，未选模块不作推断。

保留首次作答、资料阅读顺序和结果出现前的预测。分阶段题只显示当前步骤的主按钮。支持刷新续答、重新开始、PNG摘要、完整文字档案。导出配色与字体读取界面设计变量。

Hallmark Vellum parchment方向，按中文阅读调整为Songti标题和系统无衬线正文。浅纸色、墨色、靛蓝，双线页眉、细线目录与功能性图片。无需外部字体文件。视觉复核记录见上一级third-version-review.md。

## 文件与依据

- content.js：35个任务、条件化解读、来源；app.js：状态、交互、报告与导出。
- styles.css、tokens.css、base.css：样式与设计变量；index.html：入口。
- assets/cafe-scene.png为AI生成的虚构场景，同图局部/完整对比；source-notes.json保存提示词、真实尺寸与来源。字形、逻辑卡和旅行图为程序绘制。
- examples/中的报告全部为合成作答审核示例，不是真实参与者数据。

本产品是原创科普体验，不是经验证的心理量表，不给出智商、人格、人群排名或偏差强度。研究依据与每项解释边界在回看中可查。相关补充研究不冒充原书专有内容。
